Original Task: Study group feature for students

This demo replicates the .NET API functionality from github.com/PinoLopez/study-group

📋 Domain Rules

  • Group name: 5-30 characters
  • Valid subjects: Math, Chemistry, Physics
  • Creation date: auto-recorded
  • Users can join/leave (no duplicates)

🔌 API Endpoints

POST   /studygroup/create
GET    /studygroup/all?sort=desc
GET    /studygroup/search?subject=Math&sort=desc
POST   /studygroup/join?studyGroupId=1&userId=100
POST   /studygroup/leave?studyGroupId=1&userId=100
GET    /studygroup/debug/query-m-users
