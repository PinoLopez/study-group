Study Group API

Create, search, and join study groups by subject. Built with .NET 8 + EF Core + SQLite.

Open Swagger UI View on GitHub

Available Endpoints

POST /studygroup/create

Create a new study group (name + subject)

GET /studygroup/all

List all groups (sort=asc/desc)

GET /studygroup/search?subject=Math

Search by subject

POST /studygroup/join & /leave

Join/leave groups with userId

Deployed on Railway with persistent SQLite volume

.NET 8 • Entity Framework • Swagger • Tailwind landing page
